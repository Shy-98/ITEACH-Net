# Attribution

IEMOCAP label and feature loading, session-based folds, host/guest batching, and fixed-rate modality masking are adapted from [GCNet](https://github.com/zeroQiaoba/GCNet), the implementation of *GCNet: Graph Completion Network for Incomplete Multimodal Learning in Conversation*.

This repository provides the IEMOCAP four-class ITS-NAS implementation. Dataset files, extracted features, and trained checkpoints are obtained separately as described in the README.
